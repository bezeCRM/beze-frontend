# bezeCRM

bezeCRM — это кроссплатформенная CRM-система для домашних кондитеров и небольших кондитерских команд.

Приложение помогает организовать ежедневную работу: управление товарами, клиентами, заказами и финансовыми показателями бизнеса.

## Возможности

- Создание и настройка профиля бизнеса
- Добавление товаров с подробными характеристиками:
  - ингредиенты
  - начинки
  - описание
  - дополнительные параметры
- Управление заказами:
  - данные клиентов
  - добавление товаров в заказ
  - отслеживание статуса выполнения
- Уведомления о важных этапах заказа:
  - начало приготовления
  - скорое получение заказа
- Отслеживание финансовых показателей
- Аналитика и сравнение выручки за разные периоды

bezeCRM создан для упрощения рабочих процессов кондитеров и помогает меньше времени тратить на рутинное управление, уделяя больше внимания созданию продуктов.

## Технологии

React Native, Expo, TypeScript, Zustand, FastAPI, PostgreSQL

# bezeCRM

bezeCRM is a cross-platform CRM application designed for home-based confectioners and small confectionery teams.

The application helps organize daily business operations: managing products, customers, orders, and financial performance.

## Features

- Business profile management
- Product catalog with detailed characteristics:
  - ingredients
  - fillings
  - descriptions
  - additional product details
- Order management:
  - customer information
  - products included in orders
  - order status tracking
- Notifications for important order stages:
  - preparation start
  - upcoming order pickup
- Financial tracking
- Business analytics and revenue comparison

bezeCRM is designed to simplify confectioners' workflows by reducing routine management tasks and helping them focus more on creating their products.

## Technologies

React Native, Expo, TypeScript, Zustand, FastAPI, PostgreSQL
